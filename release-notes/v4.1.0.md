# 4.1.0

This release moves the building of multipart bodies into one shared helper. Service method signatures and the parts sent on the wire do not change.

## Changed

- A new supporting file, `api/multipart.ts`, exports `buildFormData`. Each service method with a multipart body passes it one entry per field, such as `['file', file, 'file']`, instead of an inline `if (...) { formData.append(...) }` block per field. Two operations that send the same fields, such as a create and an update, no longer repeat the same lines, so duplicate-code checks such as Sonar's no longer flag them.

## Migration

1. Update the generator dependency to `de.tum.cit.aet:openapi-generator-angular22:4.1.0` and regenerate the complete client.
2. Commit the new `api/multipart.ts`.
3. A parameter named `buildFormData` is now renamed to `buildFormDataParam`, as other names the generated code uses already are.
